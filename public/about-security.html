পরিচিতি ও নিরাপত্তা

প্ল্যাটফর্ম পরিচিতি

NIVORA ONE একটি বহু-মডিউল ডিজিটাল প্ল্যাটফর্মের প্রকল্প। এতে AI, ব্যবসা পরিচালনা, ই-কমার্স, গণনা এবং অন্যান্য সেবা একত্রিত করার পরিকল্পনা রয়েছে।

অ্যাকাউন্ট নিরাপত্তা

  • শক্তিশালী ও আলাদা পাসওয়ার্ড ব্যবহার করুন।
  • পাসওয়ার্ড বা OTP অন্য কারও সঙ্গে শেয়ার করবেন না।
  • অন্যের ডিভাইস ব্যবহার করলে শেষে লগআউট করুন।

ডেটা সুরক্ষা

Firebase Authentication, Firestore Rules এবং Storage Rules সঠিকভাবে কনফিগার করা প্রয়োজন। শুধু লগইন চালু থাকলেই ডেটা নিরাপদ হয়ে যায় না।

API Key সুরক্ষা

Gemini-এর গোপন API Key HTML, JavaScript বা GitHub-এ রাখবেন না। Cloudflare-এর Secret/Environment Variable ব্যবহার করুন।
